**Повторение другим участником.**

После фиксации A10 взять согласованный коммит в отдельный чистый каталог, выполнить установку из README через `uv sync --locked`, затем:

```bash
.venv/bin/python -E -m pytest tests/test_api_process.py tests/test_evidence.py -q
.venv/bin/python -E -m scripts.try_workflow --data-dir data/acceptance
.venv/bin/python -E -m scripts.export_run --data-dir data/acceptance --run-id RUN_ID --output-dir data/acceptance-export
.venv/bin/python -E scripts/check_contracts.py
.venv/bin/python -E -m scripts.check_secrets
```

RUN_ID взять из результата try_workflow. Для второго экспорта выбрать новый каталог. Проверить SHA-256 файлов по manifest.json, полноту учёта и отметку synthetic. Отдельно пройти приложение с реальными агентами и интерфейсом после интеграции; синтетический сценарий этого подтверждения не даёт.
