Особенности окружения: сеть, Docker socket и локальные сокеты потребовали запуска проверок вне песочницы. Настоящие тесты выполнялись успешно вне неё. Глобальный PYTHONPATH от ROS мешал первоначальному запуску pytest; в README добавлен `python -E`, изолирующий Python от таких глобальных настроек. Переменные APP_* при этом сохраняются.

Тестовый клиент выдаёт одно предупреждение Starlette о будущей замене httpx на httpx2. На закреплённых версиях проверки проходят; миграцию тестового клиента следует выполнять при очередном обновлении зависимостей. В текущем каркасе нет вызовов платных моделей; ключи не требуются.

Контейнерные проверки проводились в отдельном Compose-проекте strategy-a2-check. Тестовый контейнер, его сеть и том с контрольным файлом удаляются после проверки; временный локальный сервер остановлен. Изменения пользовательских файлов и git-коммиты автоматически не выполнялись, кроме файлов реализации и документации A2.

Проверки выполнены ассистентом. Повторный запуск участником команды по README остаётся независимой приёмкой A2. Возможности /health ограничены доступностью процесса: он не подтверждает готовность будущих моделей, базы или workflow.
