Проверка A3: адаптер OpenRouter

По одобренному плану реализованы единый вызов модели, structured outputs с локальной валидацией, типизированные ошибки, ограниченные повторы, регистрация Usage и пример для участника 2. Ключ и модель в пользовательском `.env` не изменялись. Отсутствовавший шаблон `.env.example` восстановлен с настройками OpenRouter.

Результаты:

- 33 теста прошли: 8 проверок backend и 25 проверок адаптера. OpenRouter имитировался через MockTransport.
- Проверены успешный запрос, совместимость Usage с A1, неверный ключ, отсутствие средств, запрет доступа, неизвестная модель, ограниченные повторы, Retry-After, тайм-аут, отказ модели, неправильный JSON и повреждённая структура ответа.
- Стоимость записывается даже при отклонённом результате; неизвестные значения не превращаются в ноль. Недопустимые ссылки схемы отклоняются до запроса. Ошибка записи события не инициирует повтор модели.
- Проверки A1 прошли: 33 схемы, 9 примеров, 17 операций API, 8 негативных сценариев.
- Пример без ключа/модели вернул CONFIGURATION_ERROR с exit code 1 и пустым usage_ids, без сетевого вызова.
- Docker-образ собран с обновлённым lock-файлом; backend пересоздан и Healthy; /health вернул HTTP 200 с {"status":"ok"}.
- git diff --check прошёл. Перемещения планов в project-notes относятся к предыдущей задаче.
