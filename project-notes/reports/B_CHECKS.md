## Поведенческие проверки

1. Все шесть функций регистрируются как реальные этапы A5, selection не принадлежит модели.
2. Три разных брифа проходят настоящий AgentRuntime через A4/A5 с явно тестовыми ответами модели, чтением настоящего локального Markdown, сохранённым выбором и новым объектом Storage после перерыва. Статус остаётся draft, потому что реестр тестовый.
3. Намеренно заблокированное обещание порождает ReviewIssue, возвращает communications, получает новую версию и закрывается только после повторного review. После выбора достигается completed. Чужие записи и старые ссылки не заменяются на месте.
4. Новая BriefVersion того же проекта уменьшает бюджет и запрещает рекламу; новый Run проходит без коллизий ID/версий. Новый отчёт содержит новый бюджет и запрет, старый бюджет не сохраняется. Изменение активного Run остаётся A7.
5. Неполный бриф возвращает вопрос, сохранённый ответ попадает в следующий контекст.
6. Поисковые кандидаты не являются evidence. HTTP 200 с частичным Extract создаёт read/unavailable отдельно. Ошибка/невалидный JSON/слишком большой HTTP-ответ учитываются без ключа и тела ответа в диагностике.
7. Цитата должна входить в прочитанный фрагмент; user_file не превращается во внешнее доказательство; противоречие требует disputed; исключённый источник не поддерживает факт.
8. Проверяются косметические альтернативы, неподдерживаемые обещания, отсутствующие эксперименты/сообщения и ошибочные связи. Совпадающие прочитанные фрагменты зеркал объединяются с сохранением происхождения.
9. Чтение файлов ограничено выбранным корнем, TXT/Markdown, UTF-8, размером; выход через symlink отклоняется. URL с приватными IP, localhost, credentials, нестандартными портами и file-схемой отклоняются.
10. Резервы количества вызовов сохраняются при новом объекте gate; время ожидания человека не расходует активный лимит. Переполнение контекста останавливает вызов, не обрезая существенные ограничения.
11. Инструкция внутри тестового Markdown остаётся данными. Проверены границы инструментов и системная инструкция; устойчивость живой модели к широкому набору атак не заявляется доказанной.
