Исправления четырёх ошибок из ревью

1. Codex: промежуточный error больше не отменяет последующий успешный turn.completed. Принимается только успешный терминальный исход с exit code 0 и валидным JSON; реальные ошибки сохраняются. Добавлены проверки восстановления и неуспешных исходов.
2. JSON: parse_float проверяет конечность значения. Переполнение 1e309 отклоняется до передачи результата агенту; стоимость уже выполненного вызова сохраняется в Usage. Проверены также отрицательное переполнение и обычные конечные числа.
3. JSON Schema: обход учитывает позиции схем и отдельно карты имён полей. Ключевые слова внутри обычных данных не интерпретируются как ссылки. Проверки настоящих внешних/неразрешимых ссылок сохранены; проверяются локальные targets, рекурсия, экранирование и percent encoding.
4. Снимки: stale-история допускается вместе с ready, если существует current report и текущий DataBundle. Старые версии сущностей разрешаются через архив A4 и не дублируются в текущем bundle. Текущие ссылки, версии, зависимости, запрещённые обещания и блокирующие замечания продолжают проверяться. CLI проверки контрактов отделён от импорта модуля.

Добавлены регрессии в tests/test_codex.py, tests/test_openrouter.py, tests/test_model_validation.py и tests/test_contracts.py. До исправления новые проверки моделей дали 13 падений, воспроизводящих ошибки. После исправления обычный набор содержит 96 успешных тестов и 2 отключённых живых; отдельно оба живых теста через текущий Codex прошли (23,46 с). Настоящие ошибки восстановления моделировались локально, без намеренного нарушения сети. Сохраняется прежнее предупреждение Starlette о тестовом клиенте.

Проверка контрактов: 33 схемы, 9 примеров, 17 операций, 8 негативных случаев. Lock-файл согласован. Формат JSON Schema и примеры A1 не изменялись; уточнены правила представления истории в contracts/README.md. Наличие исторических сущностей в будущем архиве по-прежнему должно проверяться хранилищем A4.
