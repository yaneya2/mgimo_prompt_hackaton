# Тестовые материалы

Три файла для учебного сервиса расписания. Все данные вымышленные; интервью и пилоты не проводились. Не использовать их как реальные рыночные доказательства.

В корневом .env:

```dotenv
APP_RESEARCH_MATERIALS_DIR=materials
APP_RESEARCH_FILES=["test/product.md","test/audience-hypotheses.md","test/pilot-plan.md"]
```

Пустой APP_TAVILY_API_KEY позволяет проверить обработку файлов без поиска. При заданном ключе агент дополнительно выполнит настоящий веб-поиск. После изменения .env перезапустите сервер и worker. Для другого продукта замените файлы соответствующими материалами и измените список.
