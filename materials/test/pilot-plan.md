# План проверки — ВЫМЫШЛЕННЫЙ ТЕСТ

Это предлагаемый учебный план, а не результаты проведённого эксперимента. Числа ниже — допущения для проектирования проверки, не рыночные факты.

Недели 1–2: провести 8 интервью с согласия участников и описать их существующий способ записи. Предполагаемый ответственный: основатель; роль требует назначения.
Недели 3–4: пригласить до 5 преподавателей в ручной пилот, только если интервью выявят проблему. Использовать реально доступные календарь, страницу записи и email.
Недели 5–6: измерить активацию и повторное использование; обсудить готовность платить без фиктивных платежей.

Пример условного порога: хотя бы 3 из 5 участников пилота самостоятельно используют страницу записи повторно в течение двух недель. Основание порога: учебное допущение для решения о следующем пилоте; статистической значимости нет. Исходное значение неизвестно, его нужно измерить.
Остановка: участники не видят проблемы либо для полезности требуются отсутствующие интеграции. Не обещать Telegram и онлайн-оплату ради прохождения порога.
Расходы распределять в пределах актуального бюджета брифа; стоимость API и модели учитывать отдельно по журналу приложения. Успешность плана ещё не проверена.
