# Учебные материалы и ручные кейсы

- [Комплексный кейс ремонтного сервиса](complex-repair/README.md): модель и веб-поиск, противоречия, смена бюджета, критика и отчёт. Контрольные расчёты лежат отдельно от исследовательских входов.
- [Клининговый кейс](realistic-cleaning/README.md): настоящие вызовы модели только по предоставленным файлам, без веб-поиска.
- [Два коротких кейса](test-cases/README.md): возвраты интернет-магазина и ремонт велосипедов.
- `test/` — ранние учебные файлы; не подключаются автоматически.

Каталог кейса — исходник. ZIP — копия для передачи; результаты запуска хранятся отдельно от входных данных. Для исследований приложение читает только явно выбранные TXT/Markdown из `APP_RESEARCH_FILES`. Не добавляйте в этот список контрольные ответы и не помещайте секреты в материалы.
