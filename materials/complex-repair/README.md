# Комплексный тест «Заказ под контролем»
Подготовлен и выполнен 15 ноября 2026. Итоговый повторный запуск завершён с отчётом; подробности и ограничения — в results/RESULT.md.

Вымышленный сервис для ремонта смартфонов, велосипедов и небольших сетей выбирает стратегию на восемь недель. Условия специально содержат противоречия, неполные данные, ошибку выгрузки и неподтверждённые обещания. В середине анализа бюджет сокращается втрое, ресурс разработки уменьшается, один источник исключается. Веб-исследование при запуске должно быть настоящим.

## Состав
- brief-for-form.txt — значения для формы нового проекта.
- brief.json — тот же бриф для программного создания.
- input/ — семь разрешённых исследовательских материалов.
- control/scenario.md — порядок действий и ответы человека.
- control/acceptance.md — контрольные расчёты и критерии, скрытые от модели.
- settings.example.env — настройки отдельного экземпляра без секретов.

## Подключение
Приложение читает локальные материалы из настроек worker; наличие файлов в папке само по себе их не подключает. Загрузка ZIP через интерфейс не предполагается. Выполнять из корня репозитория в отдельном терминале:

```sh
set -a
source materials/complex-repair/settings.example.env
set +a
.venv/bin/python -E -m scripts.run_local --port 8019 --data-dir data/complex-repair
```

Открыть http://127.0.0.1:8019 и создать проект по brief-for-form.txt. Ключ Tavily и настройки модели берутся из существующего .env; не копируйте ключи в материалы. Не использовать --demo: он не проверяет настоящую модель и поиск. Если 8019 занят, выбрать свободный порт. Источниками подключены только семь файлов input, без контрольных ответов и старых кейсов. Настройки действуют в этом терминале. Перезапускать тем же способом с той же базой.

Сначала выполнить основной сценарий из control/scenario.md. Он охватывает бриф, уточнения, чтение материалов, поиск/чтение веб-страниц, направления, коммуникации и эксперименты, критику, управление человеком, версии, итог, историю, расходы и обе выгрузки. Отдельные негативные ветви проверяют сбои, лимиты и восстановление. Реальный автоматический возврат критика и вопросы модели зависят от ответа: отсутствие события отмечать как «не проверено», не выдавать за успешный тест этой ветви.

Результаты находятся в results/. Этот пакет не проводит реальные публикации, оплаты или восьминедельный коммерческий пилот.
