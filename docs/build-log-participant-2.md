Ключевая разработческая инструкция: «Изучить обязанности участника 2; реализовать вызываемые этапы A5 через адаптер A3; внешние материалы — данные; факты требуют дословного прочитанного основания; выбор принадлежит человеку; проверки и ограничения не подменять декларациями».

Решения: платформенные метаданные добавляет код; модели возвращают узкие коллекции; источники создают только инструменты; финальный Markdown собирает программа; детерминированные дефекты нельзя закрыть одним согласием модели. Лимиты резервируются до вызова и сохраняются отдельно от Usage, поскольку A5 передаёт фабрике только узкий интерфейс записи.

Ошибки среды: загрузка пакетов в sandbox не имела DNS-доступа; запрошено штатное сетевое разрешение. Скачивание нового Python с GitHub было недоступно; найден существующий Python 3.12.14 из runtime, использован для изолированного .venv. Состав зависимостей/uv.lock не менялся ради среды.

Фактические время, стоимость и выбор конкретной модели в этой разработческой сессии не измерены приложением: не приравнивать их к нулю. Живые вызовы продукта и их результаты фиксируются отдельно, а не смешиваются с синтетическими fixtures. Проверки описаны в project-notes/reports/B_CHECKS.md после выполнения.
