# Соответствие техническому заданию

Основание — [сохранённый текст задания](../project-notes/task). Это пересказ исходных условий, как прямо указано в самом файле; перед подачей команда сверяет его с полными правилами. Таблица показывает материалы проверки, а не гарантирует конкурсный балл.

| Требование | Где проверять | Состояние и границы |
|---|---|---|
| От запроса до готовой стратегии | [Комплексный кейс](../materials/complex-repair/README.md), [результат](../materials/complex-repair/results/RESULT.md) | Повторный прогон завершён; первая попытка сохранена как неуспешная |
| Проверяемые источники, факты и гипотезы | [Читаемый отчёт](../materials/complex-repair/results/readable-report.md), снимки в results | Реальные веб-страницы и вымышленные внутренние данные обозначены отдельно; фрагменты не подтверждают полные тарифы |
| Разные варианты, сильные возражения | Три направления и шесть исправленных замечаний в комплексном кейсе | Это проверка учебного плана, не подтверждение спроса |
| Связность продукта, обещаний и проверки | [Промпты](../prompts/README.md), отчёт и эксперименты кейса | Обещания ограничены готовыми функциями |
| Архитектура, контекст и знания | [Архитектура](architecture.md), [описание для сдачи](submission-report.md) | Сохранённые источники и версии; отдельная векторная база знаний не заявляется |
| Модели, сервисы и инструменты | Перечень в [описании](submission-report.md) | Точный ID модели комплексного прогона не записан; не восстановлен по догадке |
| Ключевые инструкции агентов и разработки | [Runtime-промпты](../prompts/README.md), [разработка](development-prompts.md) | Сохранившиеся инструкции; полный дословный журнал разработки отсутствует |
| Остановка, исправление, продолжение | [Управление](usage.md), [правила вмешательства](../app/workflow/INTERVENTION.md), tests | Первый сложный прогон проверял смену бюджета; повторный начат отдельно |
| Воспроизводимый запуск и новые задачи | [README](../README.md), [тесты](testing.md), [оценивание](../evals/README.md) | Живые вызовы требуют собственных ключей и лимитов |
| Безопасность данных | .env.example, .gitignore, scripts/check_secrets.py | Проверка секретов не заменяет проверку разрешения на публикацию каждого материала |
| Польза дополнительных возможностей | Описание и сравнение режимов в evals | Критик исправил сроки; универсальное превосходство нескольких ролей не доказано |
| Время, расходы, ошибки, помощь человека | [Описание](submission-report.md), completed-summary.json, журналы разработки | Время прогона известно; полная цена и время разработки неизвестны |
| Документ со скриншотами и внешняя ссылка | [Описание со скриншотами](submission-report.md), [чеклист](submission-checklist.md) | Документ подготовлен в репозитории; внешняя публикация и видеозапись не выполнены |
| Личные документы участников | Профиль участника на конкурсной площадке | В Git не размещать; загрузку выполняет каждый участник |

Четыре категории оценки по 10 баллов: проработанность, масштаб использования нейротехнологий, имплементация, качество. Самооценка баллов не подменяет доказательства в таблице.
