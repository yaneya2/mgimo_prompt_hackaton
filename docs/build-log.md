# Журнал интеграции интерфейса

Запрос разработки: выполнить часть программиста 3, закончить UI/API-интеграцию, приёмку и материалы, сохранить результат в LizaLiza. Разработку и технические исправления выполнял Codex; отдельная независимая проверка человеком не заявляется. Runtime-модель измерений: gpt-6-luna через Codex; точная модель помощника разработки не записывается как выдуманный ID.

Использованные инструкции разработки: переиспользовать схемы и worker; не вызывать модель из HTTP; фиксировать выбор человека; сохранять старые версии; не показывать неизвестную цену как 0; выводить черновик только явно; экранировать внешнее содержимое; маркировать синтетический режим. Исправлены потеря worker lease при паузе, вывод старой версии как актуальной, повтор команды при сетевой ошибке, гонка исключения источника и пустой результат сравнения, ошибочно выглядевший бездефектным.

Продуктовые инструкции остаются в prompts/*-v2.md. Manifest фабрики обновлён до strategy-agents-v3 из-за контекста исключённых источников; текст промптов на holdout не подгонялся. Новая библиотека оркестрации или новая UI-зависимость не добавлены. Изменения брифа запускают безопасный полный пересчёт вместо повторного использования зависимых частей.

Сохранились ограничения: живой поиск без ключа не проверен; смысловая оценка и видеопубликация не завершены; полезность усложнения не доказана небольшой выборкой. Реальные записи содержат 17 вызовов модели, их время и неизвестную стоимость.
