# Комплект сдачи

Готово в репозитории: браузерный интерфейс, API, renderer Markdown/HTML, управление версиями и паузой, история, технические тесты, lock-файл, инструкция запуска, кадры интерфейса, PDF с архитектурой и измерениями, сценарий показа, три новых кейса и результаты сравнения режимов.

Перед внешней сдачей остаются: независимая ручная оценка по подготовленной рубрике; отдельный живой веб-прогон с собственным Tavily-ключом; запись и размещение видео по актуальным правилам; проверка открытого доступа к материалам и отправка самой заявки. Ссылка или длительность видео не выдумываются. Личные конкурсные документы и ключи хранятся отдельно от Git.

README описывает локальный запуск обоих процессов. Для контейнера с worker: `docker compose --profile worker up --build`; Codex с локальной авторизацией доступен только вне контейнера, для контейнера используется настроенный OpenRouter. Синтетический Docker-показ: задать APP_STAGE_FACTORY=demo в собственном .env. Текущий этап не включает фактическую повторную проверку Docker daemon.

Измерения и отрицательные наблюдения: `evals/README.md`. Техническая приёмка: `docs/interface.md`. Предыдущие отчёты разработки сохранены как история и могут описывать состояние до появления интерфейса.
