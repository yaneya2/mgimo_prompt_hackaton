# Промпты реальных этапов

Загрузчик `app/agents/runtime.py` использует `common-v2.md` и соответствующий `*-v2.md` для этапов brief, research, options, communications и review. Их текст является частью поведения приложения; изменение требует запуска тестов и нового живого прогона для оценки качества. Названия и версии файлов нельзя менять без обновления загрузчика и Docker-образа.

Файлы `*-v1.md` сохранены для воспроизведения исторических запусков. Они не выбираются текущим загрузчиком и не должны служить инструкцией по актуальному поведению. При переносе в архив нужно обновить ссылки в исторических документах и манифестах; до этого они остаются здесь с явной пометкой версии.

Итог собирается из сохранённых данных кодом `app/agents/report.py`; пользовательская выгрузка формируется отдельно в `app/reports/render.py`.

Инструкции создания репозитория описаны отдельно: [журнал ключевых инструкций разработки](../docs/development-prompts.md). Они не загружаются при работе приложения.
